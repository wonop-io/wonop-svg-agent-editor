# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Wonop users and agents iterating on local architecture diagrams.

## Product Purpose
Open, safely view, edit and save SVG without leaving Wonop. Success is a persisted source change with live visual feedback and no silent loss of unsaved edits (WON-887).

## Stack
Existing Wonop classic-script package with plain HTML/CSS/JavaScript. The user delegated the lightweight implementation choice and explicitly requested implementation without another planning approval.

## Capabilities and Constraints
Source editing, safe image-context preview, zoom/pan, file open/save, recoverable drafts and validation. No vector illustration suite, publishing, pushing, or Excalidraw work. Original sample is read-only task input.

## Brand Commitments
Inherit Wonop's package style guide and injected light/dark theme; content to edges, system type, quiet controls and one primary action.
