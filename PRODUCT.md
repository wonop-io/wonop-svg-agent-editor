# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Wonop users and agents iterating on local architecture diagrams.

## Product Purpose
Visually draw, select and manipulate SVG architecture diagrams without leaving Wonop, while structured agent operations share the same document. Success is a persisted source change with live visual feedback and no silent loss of unsaved edits (WON-887).

## Stack
Existing Wonop classic-script package with plain HTML/CSS/JavaScript. The user delegated the lightweight implementation choice and explicitly requested implementation without another planning approval.

## Capabilities and Constraints
Canvas-first drawing with a minimal Select/Box/Ellipse/Line/Text/Hand tool palette; direct selection, movement, primitive resizing, text editing and styling. Human controls and revision-checked structured agent commands share the same SVG and undo history. Source editing is secondary. Safe image-context rendering, zoom/pan, file open/save, recoverable drafts and validation remain. No vector illustration suite, publishing, pushing, or Excalidraw work. Original sample is read-only task input.

## Brand Commitments
Inherit Wonop's package style guide and injected light/dark theme; content to edges, system type, quiet controls and one primary action.
